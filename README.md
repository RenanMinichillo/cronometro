<h1>Stopwatch</h1>

<p>Este é um cronômetro simples desenvolvido com HTML, CSS e JavaScript. Permite iniciar, pausar e resetar a contagem do tempo de forma intuitiva.</p>

<h2>Acesse o projeto</h2>

<p>Você pode testar o cronômetro diretamente neste link: <a href="https://minichillo-stopwatch.netlify.app/" style="text-decoration: none;">STOPWATCH</a></p>

<h3>Tecnologias utilizadas</h3>

<p>HTML</p>

<p>CSS</p>

<p>JavaScript</p>

<h3>Funcionalidades</h3>

<p>Iniciar a contagem do tempo</p>

<p>Pausar e retomar a contagem</p>

<p>Resetar o cronômetro </p>

<h3>Como usar</h3>

Clique no botão <b>"Iniciar"</b> para começar a contagem.

Clique em <b>"Pausar"</b> para interromper a contagem sem resetar.

Clique em <b>"Resetar"</b> para zerar o tempo.
